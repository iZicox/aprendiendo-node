¿Cómo abrirlo con doble clic?

Abrí index.html con doble clic. La API ya incluye CORS para /api/*, así que el origen file:// puede consultarla.

Solo necesitás que wrangler dev esté corriendo. La API base por defecto es http://localhost:8787/api.

Si preferís servir el HTML desde otro puerto, podés usar un proxy:

npx http-server . -p 3000 -P http://localhost:8787/

Y abrir http://localhost:3000/.

GET, POST, PATCH y DELETE sobre /api/products y /api/categories.
